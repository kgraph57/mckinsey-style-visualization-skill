What happens in the demo
  1. The overview introduces a bounded 12-week pilot.
  2. The dispatch chart opens its evidence and source assumptions.
  3. Switching scenarios changes the route ranking.
  4. Lowering adoption changes the annual value estimate; resetting it restores the base case.
  5. Toggling manager readiness changes the score and whether the gate is met.
  6. The rollout advances through review gates and ends at the page overview.
