# Public consulting document design study

Reviewed 8 September 2026. This is a page-level study of six firms, not a list of generic inspiration links.

## Evidence and limits

Six firms; nine public documents. Eight local PDFs: 229 total pages, 36 selected pages visually inspected; McKinsey: three official web exhibits visually inspected and PDF text consulted. No native Word originals verified.

Source formats vary even within one firm. The PDF page counts describe document size, not how many pages were visually reviewed. Dates come from covers or official landing pages; PDF metadata dates are recorded separately. Text-size measurements are observations, not recommended projection sizes.

## Source-by-source findings

[Investing in productivity growth](https://www.mckinsey.com/mgi/our-research/investing-in-productivity-growth) · 2024-03-27 · Report; selected web exhibits visually inspected

## What changes in the skill

| Observed design requirement | Implemented now | Remaining fidelity work |
| --- | --- | --- |
| Assertion + exhibit identity + measure | Analytical slide header with fixed bands | Per-reference frame geometry calibration |
| Plot beside interpretation | Distribution chart with a real right-hand commentary rail | Other chart families and mixed-panel composition |
| Document-native exhibits | Compact chart export; editable caption, scope, notes and interpretation in HTML/Word | Adaptive chart-specific report type sizes |
| Reading documents differ from projection | Briefing and editorial HTML modes; A4 Word briefing exporter | Native multi-column Word report and complex footnotes |
| One publication has a coherent palette | Four semantic palettes | User-owned font/theme assets and precise per-reference palettes |
| Quantitative and qualitative evidence coexist | Editable Word paragraphs, heading styles and ruled tables; SVG with PNG fallback | Fully editable Office chart shapes/data |

## Corrections to the previous approach

A universal navy fill, serif headline, oversized metric and generous whitespace cannot describe the sampled material. In particular, dense comparison matrices, mixed text/chart pages and multi-panel exhibits are central to several publications. A report also cannot be faithfully recreated by shrinking a presentation slide: its figure title and source should belong to the document reading system.

The new analytical layout uses a 32px headline and an explicit exhibit band, while the presentation layout retains its existing larger type. This is a separate reading purpose, not automatic shrinking to fit. Colour choices are semantic and configurable; the defaults are original approximations, not claimed official brand tokens.

## How fidelity will be judged

Choose a named reference and page before rendering. Compare the same content roles at the same aspect ratio: headline band, content origin, plot proportions, text columns, annotations, source area and page furniture. Record departures explicitly. Test long labels, absent values, negative values and pagination before accepting the template. A reference reproduction is incomplete when only its colour matches.

Use [the reproduction workflow](reference-reproduction.md), the [machine-readable evidence](consulting-reference-evidence.json), and the [editable sample](../templates/reference-layouts/decision-brief.json). Raw third-party PDFs and page images remain outside the distributable repository.
