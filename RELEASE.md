# v3.0.0-rc.1 — Interactive Decision Stories

This prerelease adds connected, explorable decision stories while preserving
classic slides and static reading editions. All Project Relay data is illustrative.

## Try it

- [English motion demo](https://kgraph57.github.io/mckinsey-style-visualization-skill/site/artifacts/project-relay.motion.en.html)
- [English static edition](https://kgraph57.github.io/mckinsey-style-visualization-skill/site/artifacts/project-relay.motion.en.static.html)
- [Japanese motion demo](https://kgraph57.github.io/mckinsey-style-visualization-skill/site/artifacts/project-relay.motion.html)

Or download the self-contained HTML assets below. Press **D** in the motion
edition to run the guided demo. Use the static edition for reading and printing.

## What's included

- Six-page motion stories: click for evidence, compare scenarios, change adoption,
  fill readiness gaps, and see how those choices affect the rollout conditions.
- An English decision design with large body text, live assertion headlines,
  whitespace-led layout and no decorative panel rules.
- Japanese and English static companions generated from the same story sources.
- A separate contract-backed interactive builder with exact calculations,
  bounded state, evidence provenance and deterministic author audit tools.
- Python-standard-library core generation; optional pinned tools for browser,
  PDF and visual checks. Classic manifests remain supported.

## Scope and limitations

This is **not the stable v3 release**. v2.4.0 remains the latest stable release.
Physical iPhone/touch, native Safari, assistive technology, real OS high contrast,
browser-toolbar zoom, AirPlay/projector and hosted security-header checks remain
open in [the verification checklist](https://github.com/kgraph57/mckinsey-style-visualization-skill/blob/v3.0.0-rc.1/tests/manual/interactive-release.md).
Do not infer physical-device or accessibility certification from automated tests.

The English decision layer is tailored to the Project Relay example. It does
not automatically build arbitrary business models. The public browser trial
continues to use the classic builder.

Public inspiration and independent design choices are recorded in
[design provenance](https://github.com/kgraph57/mckinsey-style-visualization-skill/blob/v3.0.0-rc.1/references/decision-design.md).
No purchased reference templates or source code are included. This project is
not affiliated with or endorsed by McKinsey or any other consulting firm.
